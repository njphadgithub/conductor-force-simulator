Interactive Lab Guide

Zero Force Condition (θ = 0°): Set conductor direction to match magnetic field [0, 1, 0]. Notice sin(0°) = 0 resulting in zero magnetic force on the wire.

Maximum Force Condition (θ = 90°): Set conductor direction orthogonal to magnetic field (e.g., [1, 0, 0] with field [0, 1, 0]). Notice sin(90°) = 1 yielding maximum mechanical force along the orthogonal axis.
