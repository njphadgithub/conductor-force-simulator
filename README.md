# Force on a Current-Carrying Conductor - 3D Interactive Simulation

A self-contained, browser-based 3D educational simulation designed for undergraduate engineering electromagnetics instruction. Built with **Three.js** and **Tailwind CSS**, this interactive application visualizes the magnetic force on a current-carrying conductor ($\mathbf{F} = I \mathbf{L} \times \mathbf{B}$) and its scalar form ($F = B \cdot I \cdot L \cdot \sin(\theta)$) in real time with high-precision vector components and dynamic angle calculations.

Developed for academic use at the **Government College of Engineering, Chh. Sambhajinagar**.
